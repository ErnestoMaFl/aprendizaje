Tipos y conversión

Todo lo que JavaScript convierte por su cuenta, en una hoja. Pensada para imprimir y tenerla al lado mientras lees código ajeno.

Las tres reglas que resuelven casi todo
1. + con algún texto → pega. Sin texto → suma.
2. − × / % → convierten siempre a número.
3. Comparar → === siempre. Nunca ==, salvo x == null.

El +, paso a paso

"5" + 3          // "53"   hay texto → pega
5 + 3            // 8      no hay texto → suma
"5" - 3          // 2      el guion siempre convierte a número

"1" + 1 + 0      // "110"  por parejas, de izquierda a derecha
1 + 1 + "0"      // "20"   (1+1)=2, luego 2+"0"

Conversión explícita — lo que se escribe en código real

Number("42")   // 42
+"42"           // 42   (+ unario: el mismo Number, escrito corto)
String(42)     // "42"
Formularios · Todo lo que teclea un usuario llega como texto, aunque el campo sea de tipo número. Convierte con Number(...) antes de operar, o precio + 100 te dará "1200100".

NaN

  • Es de tipo "number". Significa «esta cuenta no dio un número».
  • Es contagioso: cualquier operación que lo toque devuelve NaN.
  • NaN === NaN es false. Es el único valor que no es igual a sí mismo.
  • Para detectarlo: Number.isNaN(valor).

"2" > "12"trueDos textos → diccionario: decide el 1.er carácter, "2" contra "1".

Comparar dos textos = diccionario · Carácter a carácter de izquierda a derecha; el primero que difiere lo decide todo y el resto ni se mira. La longitud no cuenta: «zapato» va después de «abecedario». Por eso "9" > "100" es true y una lista de precios guardados como texto sale desordenada. Convierte a número antes de comparar.
x == null · La única excepción útil de ==: pregunta «¿está vacío, sea null o undefined?» en un solo gesto. Para todo lo demás, ===.
